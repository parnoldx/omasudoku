Privacy policy.

Sudoku is designed with a simple principle: your puzzle progress belongs exclusively on your computer. Zero telemetry, zero analytics, zero network calls.

Effective September 10, 2026 · Maintained by Peter Arnold (parnoldx)

On this page

Summary: Sudoku does not collect, transmit, or monetize your data. The desktop application runs entirely offline.

01 The desktop application

Sudoku for Omarchy is a standalone desktop game built with PySide6 and Qt Quick. It makes no network requests of any kind.

  • No telemetry, tracking pixels, or user behavior tracking.
  • No crash reporting to external servers.
  • No user account or cloud authentication required.
  • Runs completely isolated on your machine.

02 Local files and storage

All game state data is stored locally in standard Linux XDG directories at ~/.local/share/sudoku/:

  • highscores.json: Records your personal high scores for Easy, Medium, Hard, and Master difficulties.
  • savegame.json: Preserves your active puzzle board, timer, notes, and error count so you can resume where you left off.

These files are plain JSON, readable by you, and never sent anywhere. Deleting the folder clears all data cleanly.

03 This website

This website is hosted statically via GitHub Pages. We do not use cookies, advertising trackers, or fingerprinting scripts.

Your color theme preference (Tokyo Night or Everforest) is saved locally in your browser’s localStorage under sudoku-theme. It is never transmitted across the network.

04 Third-party hosting

Because this website is hosted on GitHub Pages, GitHub (Microsoft) may collect standard web server access logs (such as your IP address, browser user-agent, and timestamp) in accordance with GitHub's Privacy Statement.

05 Source code and inquiries

The complete source code of Sudoku and this website is published under open-source licenses. You can audit every line of code on GitHub.
